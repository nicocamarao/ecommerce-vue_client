Sobre el proyecto

Una estrategia local, medible y replicable

Quien es Ismael Pisurno

Ismael Pisurno lidera un movimiento ciudadano que combina gestion de residuos, inclusion social y cultura ambiental. Su proyecto nace para resolver el problema de microbasurales con acciones continuas y datos abiertos.

Como funciona

El modelo integra vecinos, recuperadores urbanos, escuelas y comercios. Cada actor recibe protocolos simples para separar, entregar y registrar residuos reciclables y no reciclables.

Preguntas frecuentes

Todo lo necesario para empezar

Que residuos se pueden entregar?

Plastico, carton, papel, aluminio, vidrio y residuos electronicos segun calendario.

Hay costo para participar?

No. El programa es gratuito y abierto para vecinos, escuelas y comercios.

Como se mide el impacto?

Con pesaje por lote, registro de puntos recuperados y reportes barriales mensuales.
