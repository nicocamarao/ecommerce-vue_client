Bienvenido a QuantumOS Lite

Una simulación HTML5 en español de un sistema operativo educativo inspirado en computación cuántica. Aquí puedes ejecutar dos tareas: romper un cifrado César y encontrar el número menor de una lista con una visualización inspirada en superposición, oráculo y amplificación.

🎚️ Superposición
🧠 Oráculo
📈 Amplificación
📏 Medición

Abre una app desde la izquierda o usa la QConsola con comandos como run cesar --texto KHOOR o run minimo --lista 15,3,22,9,1,18.

Sugerencia: prueba el texto KHOOR con palabra objetivo HELLO para ver cómo una clave gana peso en el modo cuántico. En la app de mínimo, usa una lista como 15, 3, 22, 9, 1, 18.
